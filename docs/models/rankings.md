# Promoted Rankings

No model run has been promoted yet.

A promoted ranking must identify its immutable run ID and record:

- season, model specification, and selected lambda;
- modeling-data and code fingerprints;
- chronological split and inclusion policy;
- held-out metrics against the mean and team baselines;
- exposure threshold and complete downloadable ranking artifact;
- known limitations and review date.

Experimental rankings remain under `artifacts/models/` until they pass data,
predictive, and basketball review.
